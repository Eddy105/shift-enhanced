# Roadmap

## 0.1 Power Foundation

- Battery telemetry
- Power dashboard
- Testable telemetry model
- CI and APK artifact

## 0.2 Battery Sessions

- Persistent local sessions
- Charge/discharge tracking
- Screen-on and idle periods
- Seven-day summaries

## 0.3 Battery Analytics

- Anomaly detection
- Background activity analysis
- Network-related drain signals
- Actionable explanations

## 0.4 Hardware Diagnostics

- Battery
- Display and touch
- Camera
- Audio
- Connectivity
- Sensors

Later milestones will cover Privacy Center, Action Center and Developer Mode.
